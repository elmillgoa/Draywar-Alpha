# Raise it, don't solve it

**Implement nothing while this is open.**

## Before you raise it

- Do Fidelity + Tone settle it?
- Do Alpha docs / reputation doc already answer?
- Did journal/state already decide?

## What to write

> **What's blocked:** …
>
> **The situation:** … (plan said X; reality is Y)
>
> **Options:**
> 1. … — costs / benefits
> 2. … — costs / benefits
>
> **My recommendation:** … (include honest cost)

Real options only. Consequences in outcome terms. Never present a scope cut as neutral.

## Standing / Alpha special cases

- **Standing rules missing:** do not invent. Cite `docs/reputation_and_standing.md` gap.
- **Save schema after first save lands:** irreversibility line — say if old saves die.
- **New dependency/asset:** name licence and whether it can be committed.

## After decision

Journal `DECISION`. Update state. Amend plan docs if needed. Then continue.

# Alpha scope guard

Source: `Alpha/ALPHA_SCOPE.md`, `Alpha/ALPHA_VISION.md`.

## Hard ceilings (not targets)

| Element | Cap |
|---------|-----|
| Systems | 3–4 |
| Entities | 4–6 |
| People | 12–18 |
| Stations | 3–5 |
| Player ships | 1 (+ optional light second) |
| Recovery chains | 1 |
| Contract types | 2–3 |
| Commodities | 6–8 |

## Explicitly out of scope for Alpha

Full two-hull interlock proof, Operation layer, warehouses/arbitrage, full debt ladder, Holding endgame, rich secret-help variety, true Entity hierarchy, multi-hop cascades, large dialogue, dynamic economy, multiple recovery chains, bounty networks, customs minigames.

Architecture must still allow these later (full-sized data shapes, single standing writer).

## If a task would breach

Stop. `/escalate` with options: cut scope, defer, or (only if Elliot chooses) amend Alpha Scope with version bump.

Do not "quickly add one more Entity" without counting against the cap.

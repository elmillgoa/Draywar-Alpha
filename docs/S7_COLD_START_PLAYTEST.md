# S7 cold-start / story playtest brief

**Gate [Elliot]:** story / freeroam balance + cold start — would you refund in 2h?

## What “cold start” means

A new player, no console, no spoilers. Can they:

1. Fly, dock, and understand the station menu?
2. Find **Story** work and follow it for ~half the campaign (Acts I–II)?
3. Still freeroam (boards, trade, combat) without feeling soft-locked?
4. Feel like a freighter captain in a jurisdictional sector — not anime opera?

If the answer to (1)–(3) is no, or (4) is wrong, the gate fails.

## Suggested 60–90 minute path (no console)

1. **New Game** → life path → annexation → tip. Tip should mention Story + Journal.
2. **Dock Alpha Port** (start system). Open station menu.
3. **Story** section at top: accept **Wake haul — parts to Alpha Yard**.
4. Undock, fly to Alpha Yard (same system), dock, **Turn in**.
5. Back at Port (or wherever next Story shows): **Sealed pouch — Alpha to Beta Hub**.
   Line up on the gate, jump, dock Beta Hub, turn in.
6. **Hub manifest** at Beta Hub → return crate to Alpha Port. Peek at **Trade** while docked.
7. **Haulers bond run** at Beta Hub → Spit. Read journal blurb about loans under Services
   (optional: borrow and feel garnish; not required).
8. **Authority seal** at Alpha Yard → Port. Act I closes; Act II opens.
9. **Lane choice** (pick one only — others vanish):
   - Trade: Free Haulers Hub → Port
   - Gun: bounty at Beta Spit (kill then turn in)
   - Shadow: smuggle munitions Hub → Gamma Outpost (customs risk)
10. Raise Reach to **Friendly** (legal work / recovery) if needed, then **Ops brief**
    at Alpha Port. After complete, open **Operations** and consider a hire.

**Journal:** pause menu → Journal — open / done / locked blurbs.

# Art direction — reference images

Drop Elliot's 8 reference images here (the "WWII bomber in space" set from the
2026-08-08 planning session): hauler from multiple angles (side, front, top,
rear, 3/4), the fighter front view, the cockpit mood shot, the hangar mood
shot.

Suggested names: `hauler_34.png`, `hauler_side.png`, `hauler_top.png`,
`hauler_rear.png`, `hauler_front.png`, `fighter_front.png`,
`cockpit_mood.png`, `hangar_mood.png` — but any clear names work.

These are the seed inputs for the model bake-off
(`docs/GRAPHICS_PHASE_PLAN.md`, "Pre-pass job") and the style anchor for the
whole graphics pass (`docs/GRAPHICS_PASS_DESIGN.md` §2). The style bar for
every generated or sourced asset is: would it sit naturally next to these
images?

`bakeoff/` (created by the bake-off session) holds the side-by-side generation
results and scorecard.
